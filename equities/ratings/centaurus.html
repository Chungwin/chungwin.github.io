Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 2.05 times its price by Dec 2030. Worked out on paper, that would happen at A$0.089 a share. But at that price a share would still be worth A$0.274 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

Why

Expensive. At A$0.36 (close of Fri 13 Nov 2026) the expected value of a share at the end of 2030 is 0.83 times today's price, under the 1.10× line for expensive over that 4.1-year horizon. The expected value weighs a share's value if the plan works and if it fails by their chances. To build Jaguar, Centaurus needs about US$177M of new shares on top of US$250M of debt that is not yet signed: more than the company's whole market value today. So even a funded and built Jaguar is worth only 1.00 times today's price, valued at what the market pays for funded mines being built: 0.57 times their study value (the after-tax net present value, NPV, in their own mine studies), measured on enterprise value (EV: shares plus debt minus cash), with the build money added. There are no nickel peers, so gold and silver builders are borrowed. A late build is worth 0.74×, a stalled project 0.76×: a late build still needs the build money, raised in new shares, and counts later, while a stalled project spends nothing more. The analyst's chance that it works (a judgement): 30%.

What would change the rating

Price alone won't make this cheap. What could raise the value: closing the funding package (senior debt and the rest of the equity; company: Q4 2026), China's approval of the second tranche of CNGR (an offtake buyer and shareholder) (expected 31 Dec 2026 in the research records, not re-checked), the shareholder meeting for that tranche (15 Jan 2027), its conditions being met by 31 Jan 2027 or it lapses, and a final investment decision (FID), which the thesis breaker (a dated test, set in advance, that would show the case is wrong) requires by 31 Aug 2027. On the numbers it would turn fair with nickel above about US$19,400/t, or if funded builders traded near 1.08 times their study value.

Already expensive. It would turn fair only below about A$0.230 with nothing else changed. It gets worse with no final investment decision (FID) by 31 Aug 2027, LME (London Metal Exchange) nickel averaging below US$14,000/t for a calendar month, or the remaining equity priced below A$0.288 a share.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Centaurus Metals (ASX: CTM) - value rating v0.4.1 (16 Nov 2026). US$M unless marked; share values A$.
# Horizon to 31 Dec 2030 (4.13 years; cheap 2.046x, expensive 1.103x).
# Rule set v0.4.1: A1 on EV / study NPV (own cash and raise credited separately): the four funded or building
# names measured at today's metal, pooled (no nickel group); capex and reserve added once, debt deducted.
# F3: q = 0.4, late = works value with the reserve spent, discounted 2 years at 10.668%. F1: stalled at the cap
# (Centaurus's own EV today, US$131.3M) + half the development spend, F2 raise.
AUD = 1.1052 / 1.6288
DEFAULTS = dict(
    P=0.36,            # share price, A$ (start close 13 Nov 2026)
    pw=0.35, q=0.4, delay=2.0,
    npv=406.7,         # Jaguar after-tax NPV8 at US$16,025/t nickel (A2 line through the study's two cases)
    ni=16025.0,
    ev_nav=[185.0 / 647.5, 173.1 / 323.8, 684.0 / 1144.6, 4275.6 / (0.9 * 4830.2)],  # Silver Tiger, Denarius, GoGold, Montage
    capex=379.6, reserve=40.0, head_office=16.8, fin_costs=35.6,
    debt=250.0, tranche2=15.0, tranche2_sh=50.3,
    stalled_A=134.6, stalled_s=8.1,   # US$M: cap 131.3 + half the development spend 3.4; shortfall 8.1
    years=4.13,
)
SHARES = 658.192696
NIL_OPTIONS = 13.0254
CASH = 43.5 * AUD
R = 1.5 ** 0.25

def npv_at(ni):
    """Study nickel-only sensitivity with the real at today's 5.66: US$216M per +10% (US$1,980/t) around 406.7."""
    return 406.7 + (ni - 16025.0) * 216 / 1980

def _m(i):
    s = sorted(i['ev_nav']); n = len(s)
    return i.get('m', s[n // 2] if n % 2 else (s[n // 2 - 1] + s[n // 2]) / 2)

def _branches(i, P):
    npv = i['npv'] if i['ni'] == 16025.0 else npv_at(i['ni'])
    opt50 = 22.025955 if P > 0.50 else 0.0                           # A$0.50 options, expire 30 Nov 2027
    mkt = i['capex'] + i['reserve'] + i['head_office'] + i['fin_costs'] - CASH - i['debt'] - i['tranche2'] - opt50 * 0.50 * AUD
    new = max(mkt, 0.0) / (0.8 * P * AUD)
    sh = SHARES + NIL_OPTIONS + opt50 + i['tranche2_sh'] + new
    Vw = _m(i) * npv + i['capex'] + i['reserve'] - i['debt']
    Mw_ps = Vw / sh / AUD
    Ml_ps = (Vw - i['reserve']) / sh / AUD / R ** i['delay']
    A, s = i['stalled_A'], i['stalled_s']
    n0 = SHARES + NIL_OPTIONS                                         # nil-price options are in the money (C4)
    p = 0.8 * (A - s) / n0; Ms_ps = A / (n0 + s / p) / AUD
    Mf_ps = i['q'] * Ml_ps + (1 - i['q']) * Ms_ps
    return dict(m=_m(i), npv=npv, market_equity=mkt, new_shares=new, shares_works=sh, Mw_ps=Mw_ps,
                M_late_ps=Ml_ps, M_stalled_ps=Ms_ps, Mf_ps=Mf_ps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    Eq0 = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['M_stalled_ps']) / P
    y = i['years']
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, M_late=b['M_late_ps'] / P, M_stalled=b['M_stalled_ps'] / P,
                E=E, E_q0=Eq0, cheap_line=2 ** (y / 4), exp_line=1.1 ** (y / 4), per_year=E ** (1 / y) - 1)

def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.002, steps=4000):
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = 10 * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
