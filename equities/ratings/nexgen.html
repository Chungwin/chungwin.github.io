Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 1.96 times its price by Sep 2030. Worked out on paper, that would happen at C$2.89 a share. But at that price a share would still be worth C$3.85 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

The expected value weighs a share's value if the plan works and if it fails by their chances. The price is already 1.16 times the value in the 2024 study (its after-tax net present value, NPV, at today's uranium), before a C$2.3B funding gap with nothing signed. Valued at what the market pays Denison, the one uranium company building a mine (1.15 times its study value on enterprise value, EV: shares plus debt minus cash), with the capex still to spend added and new debt deducted, an on-time build is worth 0.95 times today's price, a late one 0.75× and a stalled one 0.35×. The analyst's chance of an on-time build (a judgement): 40%.

What would change the rating

Price alone won't make this cheap. What could raise the value: the first concrete pour at the production shaft (16 Dec 2026), ground freezing (Jan to Mar 2027), shaft excavation (from Q3 2027) and, above all, the financing package and any capex re-estimate (by 30 Sep 2027; cash lasts to the end of Q3 2027). On the numbers it would turn fair with long-term uranium near US$143/lb, or if the market paid near 1.97 times study value for a mine at first ore.

Already expensive. It would turn fair only below about C$6.67 with nothing else changed. It gets worse with a capex re-estimate above C$2.2B, a funding package with a large share issue, or uranium falling back towards US$80/lb (expected value 0.59×).

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# NexGen Energy (TSX: NXE) - value rating v0.4.1 (16 Nov 2026). C$M; share values C$.
# Horizon to the works date 30 Sep 2030 (3.88 years; cheap 1.959x, expensive 1.097x).
# Rule set v0.4.1: A1 on EV / study NPV (own raise and debt credited separately): one uranium peer, Denison
# (EV US$1,958M at 13 Nov 2026), read two ways (Phoenix alone; Phoenix + Gryphon at its own deck), midpoint;
# all capex still to spend (2,234.2, whoever pays it) added once, new debt deducted; debentures convert above C$15.30. F3: q = 0.5, late = the late funding case
# discounted 1.5 years at 10.668%. F1: stalled at C$3.85 a share (uranium EV per lb median, F2 raise).
FX = 1.5758 / 1.1052
DEFAULTS = dict(
    P=11.05, pw=0.45, q=0.5, delay=1.5,
    npv=6535.6,        # Rook I after-tax NPV8 at US$94.775/lb (spot/long-term average), X1 at the ECB rate
    ev_nav=[1958.0 * FX / 2087.1, 1958.0 * FX / 2908.1],   # Denison EV / Phoenix 95%; / (Phoenix + Gryphon) 95%
    into_project=2234.2,   # remaining indexed capex, whoever pays it (own cash 303.5 + new money 1,930.7)
    debt_works=1679.0, equity_works=608.2,
    equity_late=1453.5,    # late: half of a C$2,907M gap as equity, the rest as debt
    stalled_ps=3.85,       # C$ per share (A = 3,156.2, s = 417.8, n = 688.89M; F2)
    years=1417 / 365.25,
)
SHARES = 688.034761
OPT_N, OPT_K = 22.9926, 6.24      # half of 45,985,100 options counted at the average 2026 exercise price
INT_SH0 = 2.46                    # shares for the 3% coupon at US$7.75 (start close)
R = 1.5 ** 0.25

def npv_at(u):
    """Study points (C$M, after tax, 2023 $) in study terms: price x 1.02658 (X1)."""
    pts = [(50, 2100), (80, 4890), (95, 6320), (100, 6790), (150, 11520)]
    x = u * FX / (1 / 0.72)
    for (a, va), (b, vb) in zip(pts, pts[1:]):
        if x <= b or b == 150: return va + (x - a) * (vb - va) / (b - a)

def _m(i):
    s = i['ev_nav']; return i.get('m', (s[0] + s[1]) / 2)

def _branches(i, P):
    npv = i['npv'] if 'u' not in i else npv_at(i['u'])
    opt = OPT_N if P > OPT_K else 0.0; proc = opt * OPT_K
    int_sh = INT_SH0 * 11.05 / P
    sh_w = SHARES + i['equity_works'] / (0.8 * P) + opt + int_sh
    Mw_ps = (_m(i) * npv + i['into_project'] - i['debt_works'] + proc) / sh_w
    if Mw_ps > 15.30:      # debentures (US$250M, C$15.30) convert: 23.30M shares, principal no longer repaid
        sh_w += 23.299161
        Mw_ps = (_m(i) * npv + i['into_project'] - (i['debt_works'] - 356.5) + proc) / sh_w
    sh_l = SHARES + i['equity_late'] / (0.8 * P) + opt + int_sh
    Ml_ps = (_m(i) * npv + i['into_project'] - i['equity_late'] + proc) / sh_l / R ** i['delay']
    Ms_ps = i['stalled_ps']
    Mf_ps = i['q'] * Ml_ps + (1 - i['q']) * Ms_ps
    return dict(m=_m(i), npv=npv, shares_works=sh_w, shares_late=sh_l, Mw_ps=Mw_ps, M_late_ps=Ml_ps,
                M_stalled_ps=Ms_ps, Mf_ps=Mf_ps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    Eq0 = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['M_stalled_ps']) / P
    y = i['years']
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, M_late=b['M_late_ps'] / P, M_stalled=b['M_stalled_ps'] / P,
                E=E, E_q0=Eq0, cheap_line=2 ** (y / 4), exp_line=1.1 ** (y / 4), per_year=E ** (1 / y) - 1)

def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.05, steps=4000):
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = 10 * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)

# desk, 16 Nov: the counted case
DEFAULTS.update({'pw': 0.4})
