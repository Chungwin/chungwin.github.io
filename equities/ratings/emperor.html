Why

A share is worth about 1.56 times today's C$0.40 in four years at the desk's 33% chance: about 12% a year, just above the 1.5 times (10.7% a year) the desk asks for and short of the 2.0 times needed for cheap. Today's price assumes a 31% chance, about the desk's, so there is no gap to name in either direction. The figure rests on the standard peer value for a gold company with a first study (US$189 an ounce); on the closest match alone (Galleon, US$73) it would read expensive.

What would change the rating

A price at or below about C$0.295 with nothing else changed; a Duquesne West resource with about half the ounces Indicated and a stated pit (raises the chance: cheap needs 48%); a financing at or above C$0.35; gold above about US$4,640.

A price above about C$0.58; a missed or renegotiated option payment; a resource update with less than a third Indicated; evidence that a first-study Emperor is worth nearer Galleon's US$73 an ounce than US$189 (below about US$114 an ounce the rating is expensive); a chance of 17% or less; gold below about US$3,080.

Thesis breakers

Set in advance: any one of these would mean the plan has failed or the rating must be redone.

  • No release by 31 Jan 2027 confirming the year-4 option payment (C$2.5M + 3.5M shares), or the option renegotiated into more shares or a longer earn-in.
  • Duquesne West resource update not published by 30 Sep 2027, or published with less than 500,000 oz Indicated or less than 1.2 Moz in total.
  • An equity raise priced below C$0.25, or more than 260M basic shares outstanding before a PEA is published.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Emperor Metals (CSE: AUOZ) - value rating v0.4.1 (16 Nov 2026). C$M; share values C$. Unchanged rules.
# No study: works at gold PEA EV per oz (median US$188.53, New Found) on 1.46 Moz; fail at the F1 cap (own US$35.10/oz
# = EV at the start close), F2 raise; q = 0.
FX = 1.5758 / 1.1052
DEFAULTS = dict(
    P=0.40, pw=0.33, per_oz=188.53, moz=1.46, au=3886.3, elasticity=1.92,
    stalled=73.053, wc=4.4, spend_works=25.75, spend_fail=25.25, years=4.0,
)
SHARES = 196.132505
WARRANTS = [(4.178417, 0.35), (0.20004, 0.15), (19.857499, 0.35), (1.645499, 0.20), (2.875834, 0.35)]
OPTIONS = [(0.4, 0.18), (1.5, 0.17), (3.75, 0.15), (2.4, 0.10), (9.35, 0.20)]
HI = 10

def _branches(i, P):
    Vw = i['per_oz'] * i['moz'] * FX * (1 + i['elasticity'] * (i['au'] / 3886.3 - 1))
    itm = [(n, k) for n, k in WARRANTS + OPTIONS if k < P]
    money = sum(n * k for n, k in itm); n_i = sum(n for n, _ in itm)
    opt_sh = 7.5 if P >= 0.20 else 1.5 / P          # shares owed to Duparquet (C$1.5M worth below C$0.20)
    gap = max(0.0, i['spend_works'] - i['wc'] - money)
    sh = SHARES + n_i + opt_sh + gap / (0.8 * P)
    A = i['stalled']
    fx = [(n, k) for n, k in WARRANTS if k <= 0.20] + OPTIONS    # the C$0.35 warrants lapse in a stall
    n0 = SHARES + sum(n for n, _ in fx) + 7.5
    s = i['spend_fail'] - i['wc'] - sum(n * k for n, k in fx)
    p = 0.8 * (A - s) / n0; fv = A / (n0 + s / p)
    return dict(gap=gap, shares_works=sh, Mw_ps=Vw / sh, M_stalled_ps=fv, Mf_ps=fv)
def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.005, steps=4000):
    """Highest price at or below `hi` where E(P) >= line (scan down on a log grid, then bisect)."""
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = HI * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    Eq0 = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['M_stalled_ps']) / P
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, M_stalled=b['M_stalled_ps'] / P, E=E, E_q0=Eq0,
                per_year=E ** (1 / i['years']) - 1)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
