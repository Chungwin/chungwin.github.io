Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 2.00 times its price by Nov 2030. Worked out on paper, that would happen at C$0.44 a share. But at that price a share would still be worth C$0.52 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

Why

Expensive. At C$2.18 (close of Fri 13 Nov 2026) the expected value of a share in four years is 0.61 times today's price (about -11% a year), under the 1.1× line below which a share counts as expensive. The expected value weighs what a share is worth if the plan works and if it fails by their chances. The plan: Machine A (600 tonnes a year of rare-earth oxide) runs on commercial feed with a binding offtake (a contract to sell the output) by 31 Dec 2027. Even certain success is worth only 1.05 times today's price, because the market already pays about US$300k for each tonne a year of Machine A's capacity, 69% of what it pays for Lynas's operating, mine-fed output, before the machine is installed or any binding contract is signed. If the plan fails, a share is worth 0.47 times today's price. The analyst's chance that it works (a judgement): 25%.

What would change the rating

Price alone won't make this cheap. What could raise the value: factory-acceptance results for Machine A (expected by 31 Dec 2026, marked overdue in the research records); its installation and commissioning (H1 2027); and a first binding feed or offtake contract (required by 31 Dec 2027). A binding feed and offtake contract with committed outside money for Line 1 would let the full 3,600 tonnes a year be valued like an operating producer. Canada's contribution agreement for Kingston has no company date.

Already expensive. It stays so at any price above about C$1.16 with nothing else changed, and it gets worse if Machine A's commissioning is re-dated past 30 Jun 2027, or if equity is raised below C$1.50 a share or cash falls below C$40M before Machine A is commissioned (these are thesis breakers: dated tests, set in advance, that would mean the rating must be redone).

Thesis breakers

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Ucore Rare Metals (TSXV: UCU) - value rating v0.4.1 (16 Nov 2026). C$M; share values C$. Unchanged rules.
# Works: Machine A (600 tpa) running with a binding offtake by 31 Dec 2027, at Lynas's EV per tpa of REO output
# (US$433.4k; one name). Fail: q = 0.4 late (works EV discounted 1.5 years at 10.668%, 30 more of overhead) and a
# stall (Element 25's EV + half Machine A's capex = C$96.1M, F2 raise).
USD = 1.1052 / 1.5758                          # US$ per C$
DEFAULTS = dict(
    P=2.18, pw=0.30, q=0.4, delay=1.5,
    ev_per_tpa=433.4, tpa=600,      # US$k per tpa (Lynas, 27 Oct 2026); Machine A capacity
    ndpr=110.0,                     # US$/kg; works and late EV move in proportion (estimate)
    uses=55 / USD + 10 / USD + 25.0,  # Machine A remaining + first fill + 5 quarters of overhead (estimates)
    cash=75.0, milestones=21.1 / USD, late_extra=30.0,
    stalled=96.1, stalled_s=13.4,
    years=4.0,
)
SHARES = 152.070251
UNITS = 0.640 + 0.025710
INSTR = [(0.364511, 0.75), (0.501113, 1.75), (3.103334, 0.8787), (1.2, 1.3748)]  # warrants; option buckets (strike
# table not available: buckets rebuilt from v0.4's counts and proceeds at C$2.18, C$1.22 and C$0.61)
R = 1.5 ** 0.25
HI = 10

def _branches(i, P):
    itm = [(n, k) for n, k in INSTR if k < P]
    n_i = sum(n for n, _ in itm); money = sum(n * k for n, k in itm)
    EVw = i['ev_per_tpa'] * i['tpa'] / 1000 / USD * i['ndpr'] / 110.0
    gap = max(0.0, i['uses'] - i['cash'] - i['milestones'] - money)
    base = SHARES + UNITS + n_i
    Mw_ps = EVw / (base + gap / (0.8 * P))
    Ml_ps = EVw / R ** i['delay'] / (base + (gap + i['late_extra']) / (0.8 * P))
    n0 = SHARES + UNITS + 0.865624
    A, s = i['stalled'], i['stalled_s']; p = 0.8 * (A - s) / n0
    Ms_ps = A / (n0 + s / p)
    return dict(EV_works=EVw, gap=gap, shares_works=base + gap / (0.8 * P), Mw_ps=Mw_ps, M_late_ps=Ml_ps,
                M_stalled_ps=Ms_ps, Mf_ps=i['q'] * Ml_ps + (1 - i['q']) * Ms_ps)
def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.005, steps=4000):
    """Highest price at or below `hi` where E(P) >= line (scan down on a log grid, then bisect)."""
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = HI * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    Eq0 = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['M_stalled_ps']) / P
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, M_stalled=b['M_stalled_ps'] / P, E=E, E_q0=Eq0,
                per_year=E ** (1 / i['years']) - 1)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
