Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 2.00 times its price by Nov 2030. Worked out on paper, that would happen at A$0.375 a share. But at that price a share would still be worth A$0.816 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

What would change the rating

Price alone won't make this cheap. What could raise the value: the La Verde maiden resource (no company date; expected by 31 Dec 2026 on the research team's reading, and a thesis breaker (a dated test, set in advance, that would show the case is wrong) trips if it is below 350 million tonnes or not out by 31 Mar 2027), a revised pre-feasibility study including La Verde (2027), the environmental submissions for the water intake and the mine (Q2 2027), and a partner (a process run by the bank BMO) or a Huasco Water deal, which the plan needs by 31 Dec 2028. A partner who paid Hot Chili's whole share of the build equity would lift the expected value to about 1.26×, fair.

Already expensive. It would turn fair only below about A$0.835 with nothing else changed. It gets worse with no binding partner or water deal by 31 Dec 2028, a La Verde resource below 350 million tonnes, or a share issue below A$1.00.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Hot Chili (ASX/TSXV: HCH) - value rating v0.4.1 (16 Nov 2026). US$M unless marked; share values A$.
# Rule set v0.4.1: A1 on EV / study NPV (own raise credited separately): copper 'FS / permitted, unfunded', whole
# group (fewer than five names), Western on its X1 study value; Hot Chili's share of the equity put into the
# project added once. F1: the stalled project at the cap (Hot Chili's own EV per lb today, 2.28 c/lb on 7,007 Mlb
# = its EV of US$159.8M), F2 raise; q = 0 (works state is a funded build, not production).
AUD = 1.1052 / 1.6288                          # US$ per A$, ECB 13 Nov 2026
CAD_FX = 1.5758 / 1.1052                       # C$ per US$
DEFAULTS = dict(
    P=1.305,           # share price, A$ (start close 13 Nov 2026)
    pw=0.36,
    cu=6.173,
    ev_nav=[240.0 / (11565.2 / CAD_FX), 44.2 / 915.2, 901.1 / 2895.1, 486.4 / 1685.5],  # Western, Highland, Ivanhoe, Marimaca
    stake=0.897 * 0.70, # Hot Chili's share after a partner takes 30% of its 89.7%
    capex=1270.0, overrun=0.10, debt_share=0.55, partner=220.0, pre_build=80.0,
    stalled=159.8,     # US$M, the cap: 2.28 c/lb x 7,007 Mlb (= Hot Chili's EV at the start close)
    cash_A=29.2, spend_fail_A=85.0,
    years=4.0,
)
SHARES = 202.901656 + 5.149759                 # shares + rights with no exercise price

def npv_today(cu):
    """Costa Fuego PFS after-tax NPV8, US$M, 100%: 1,200 @ 4.30, 1,610 @ 4.70, 2,180 @ 5.30; last step US$95M per 10c."""
    if cu >= 4.70: return 1610 + (cu - 4.70) * 950
    return 1200 + (cu - 4.30) * 1025

def _m(i):
    s = sorted(i['ev_nav']); n = len(s)
    return i.get('m', s[n // 2] if n % 2 else (s[n // 2 - 1] + s[n // 2]) / 2)

def _branches(i, P):
    eq_total = i['capex'] * (1 + i['overrun']) * (1 - i['debt_share'])
    hch_eq = i['stake'] * eq_total                                   # equity put into the project (HCH share)
    raise_us = i['stake'] * (eq_total - i['partner']) + i['pre_build'] - i['cash_A'] * AUD
    new = raise_us / AUD / (0.8 * P)
    Vw = _m(i) * npv_today(i['cu']) * i['stake'] + hch_eq
    Mw_ps = Vw / AUD / (SHARES + new)
    A = i['stalled'] / AUD; s = i['spend_fail_A'] - i['cash_A']
    if A - s <= 0: Ms_ps = 0.0
    else:
        p = 0.8 * (A - s) / SHARES; Ms_ps = A / (SHARES + s / p)
    return dict(m=_m(i), npv=npv_today(i['cu']), raise_A=raise_us / AUD, new_shares=new, shares_works=SHARES + new,
                Mw_ps=Mw_ps, M_stalled_ps=Ms_ps, Mf_ps=Ms_ps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, E=E, per_year=E ** (1 / i['years']) - 1)

def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.01, steps=4000):
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = 10 * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
