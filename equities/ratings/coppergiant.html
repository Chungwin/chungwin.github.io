Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 2.00 times its price by Nov 2030. Worked out on paper, that would happen at C$0.280 a share. But at that price a share would still be worth C$0.536 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

Why

Expensive. At C$0.85 (close of Fri 13 Nov 2026) the expected value of a share in four years is 0.70 times today's price, under the 1.1× line for expensive. The expected value weighs a share's value if the plan works and if it fails by their chances. Mocoa has no economic study yet, so it is valued per pound of copper in the ground. Companies one stage further, with a pre-feasibility study (the second of the three standard mine studies), trade at 2.29 US cents a pound today; Mocoa already trades at 1.09 cents, and the share count grows about 48% on the way (from 262.5 million to about 388 million). So even certain success pays about 1.14 times today's price, and a failure about 0.61×. The analyst's chance of success by 2030 (a judgement): 18%.

What would change the rating

Price alone won't make this cheap. What could raise the value: the first study (a preliminary economic assessment, PEA, the earliest and least certain mine study) filed on SEDAR+ (Canada's official filings database) (company: by 30 Nov 2026; a thesis breaker (a dated test, set in advance, that would show the case is wrong) trips if it is not filed by 31 Dec 2026), final approval of Mocoa's land-use plan (by end-2026, a press report, unconfirmed), and a court or agency decision on Corpoamazonia's resolutions (undated; it would raise the chance, not the value). On the numbers the share turns fair only if the PEA's value at today's copper (its after-tax net present value) is about US$25B or more; the cheap line would take about US$62B. A miner buying in at or above today's price would also help.

Already expensive. It would turn fair only below about C$0.53 with nothing else changed. It gets worse with a court order against the Mocoa ground, a PEA worth less than about US$8.5B at today's copper (that would lower the value if it works), or more new shares than the about 126 million assumed (388 million shares in all).

Thesis breakers

Set in advance: any one of these would mean the plan has failed or the rating must be redone.

  • A court order or an ANM/ANLA act that suspends exploration at Mocoa or excludes the deposit area, at any date before 13 Nov 2030.
  • The PEA shows an after-tax NPV (8%) below US$0.8B at a copper price of US$4.75/lb or less, or is not filed by 31 Dec 2026. This is at the study's own, lower copper price. The study values under “What would change the rating” are at today's US$6.17/lb: a study's value rises steeply with the copper price, and projects one stage further trade at only about 3 cents per dollar of study value, which is why those figures are so much larger.
  • Fully diluted shares above 420M before a PFS is published (today 361.84M), or cash below C$15M with no financing announced.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Copper Giant Resources (TSXV: CGNT) - value rating v0.4.1 (16 Nov 2026). C$M; share values C$. Unchanged rules.
# No study: works at copper PFS EV per lb (median 2.29 c/lb, Surge / Hot Chili / Solaris) on 11,490 Mlb; fail at the
# F1 cap (Copper Giant's own 1.09 c/lb = its EV at the start close), F2 raise; q = 0.
FX = 1.5758 / 1.1052
DEFAULTS = dict(
    P=0.85, pw=0.20, works_c_lb=2.29, lb=11490.0, cu=6.173, elasticity=1.8,
    stalled=178.15,    # C$M: EV at the start close (cap)
    cash=45.0, spend_works=104.0, spend_fail=74.0, years=4.0,
)
SHARES = 262.526544
# (M, strike C$, expires by Jul 2027) - warrants (C$0.50 Dec-2026 series net of 5.55M exercised after June), options
SERIES = [(16.463625, 0.60, False), (18.472902, 0.40, False), (28.306453, 0.28, True), (8.191, 0.50, True),
          (4.258168, 0.20, True), (5.092267, 0.30, True), (0.960428, 0.50, True), (0.057, 0.35, True),
          (3.7875, 0.18, False), (4.0, 0.48, False), (0.525, 0.34, False), (0.25, 0.32, False), (0.1, 0.25, False)]
HI = 10

def _branches(i, P):
    itm = [(n, k, e) for n, k, e in SERIES if k < P]
    money = sum(n * k for n, k, _ in itm); n_i = sum(n for n, _, _ in itm)
    Vw = i['works_c_lb'] / 100 * i['lb'] * FX * (1 + i['elasticity'] * (i['cu'] / 6.173 - 1))
    gap = max(0.0, i['spend_works'] - i['cash'] - money)
    sh_w = SHARES + n_i + gap / (0.8 * P)
    A = i['stalled']
    # fail: in the money at P AND (expiring by July 2027 OR struck below the fail value per share)
    ex, fv = [], A / SHARES
    for _ in range(5):
        ex = [(n, k) for n, k, e in itm if e or k < fv]
        n = SHARES + sum(x for x, _ in ex); s = max(0.0, i['spend_fail'] - i['cash'] - sum(x * k for x, k in ex))
        p = 0.8 * (A - s) / n; fv = A / (n + s / p)
    return dict(gap=gap, shares_works=sh_w, Mw_ps=Vw / sh_w, M_stalled_ps=fv, Mf_ps=fv)
def _E(i, P):
    b = _branches(i, P); return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.005, steps=4000):
    """Highest price at or below `hi` where E(P) >= line (scan down on a log grid, then bisect)."""
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = HI * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi); cheap = _cross(i, 2.0 ** (y / 4), hi)
    fps = _E(i, cheap)[1]['M_stalled_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fps)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {})); P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    Eq0 = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['M_stalled_ps']) / P
    return dict(b, Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, M_stalled=b['M_stalled_ps'] / P, E=E, E_q0=Eq0,
                per_year=E ** (1 / i['years']) - 1)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
