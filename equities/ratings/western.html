Why

Fair. At C$2.04 (close of Fri 13 Nov 2026) the expected value of a share in four years is 1.38 times today's price (about 8% a year): above the 1.1× line for expensive, below the 2.0× line for cheap. The expected value weighs a share's value with and without a deal by their chances. It rests on one input: what a buyer or funder would pay for Casino. At the median that copper projects with a feasibility study trade at today (0.22 of their study value at today's metal, measured as price to net asset value (the study value of the projects plus cash, minus debt), P/NAV), a deal makes a share worth 5.27 times today's price; with no deal it is worth 0.40 times today's price. The analyst puts the chance of a bid or funding deal by 13 Nov 2030 at 20% (a judgement). The price is low for known reasons: no permit timetable, a C$3.6B build against a C$462M company, and Rio Tinto's rights ending on 30 Nov 2026.

What would change the rating

Cheap below about C$1.41, if there is also a written reason the market is wrong, a dated catalyst and no tripped thesis breaker. Without a price move it would take evidence that a buyer or funder would pay about 0.35 or more of Casino's study value at today's metal (the peer median is 0.22): for example Rio Tinto renewing its rights with a named path (they end on 30 Nov 2026 unless both sides extend them), a dated timetable from YESAB (the Yukon assessment board), or a signed funding deal.

Expensive above about C$2.56 with nothing else changed, or if deals for comparable projects came in at about 0.16 of study value or less, with a written reason. The thesis breakers (dated tests, set in advance, that would show the case is wrong) point the same way: Rio Tinto below 5.0% and Mitsubishi Materials below 3.0% of the shares, no YESAB Panel terms of reference by 31 Dec 2027, or a share issue below C$2.00.

Thesis breakers

Set in advance: any one of these would mean the plan has failed or the rating must be redone.

  • Rio Tinto below 5.0% and Mitsubishi Materials below 3.0% at any date before 13 Nov 2030.
  • No YESAB Panel terms of reference by 31 Dec 2027.
  • A share issue below C$2.00, or cash below C$60M, before a partner or bidder is named.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Western Copper and Gold (TSX: WRN) - value rating v0.4.1 (16 Nov 2026). C$ unless marked.
# Rule set v0.4.1: A1 on P/NAV (no own cash or raise credited), whole-group median for groups of fewer
# than five names; F1 central = lowest name of the stall group (works and stall groups coincide); q = 0.
FX = 1.5758 / 1.1052                      # C$ per US$, ECB reference rates 13 Nov 2026
DEFAULTS = dict(
    P=2.04,            # share price, C$ (start close 13 Nov 2026, TSX)
    pw=0.25,           # chance it works (desk), 0-1
    cu=6.173,          # copper, US$/lb (LME cash 13 Nov 2026)
    au=3886.3,         # gold, US$/oz (COMEX close 13 Nov 2026)
    pnav=[0.040, 0.071, 0.364, 0.373],  # copper FS / permitted P/NAV today: Western (X1), Highland, Marimaca, Ivanhoe Electric
    fail_c_lb=1.20,    # stalled value, US cents per lb Cu (Highland, lowest name of the group)
    lb=10720.0,        # Mlb Cu, all categories (gold not counted)
    cash_fail=4.469,   # C$M cash at 13 Nov 2030 if no deal: 120.669 - 30 x 4.12 + 7.4 interest (estimate)
    years=4.0,
)
SHARES = 226.276171                       # M, MD&A 5 Nov 2026
OPTIONS = [(1.000000, 1.35), (2.814600, 1.58), (0.709668, 2.04), (1.112000, 2.19), (0.685256, 4.18)]  # (M, strike C$)
OPT_UNKNOWN = 0.400000                    # M options added after 30 Sep 2026, terms not available: shares, no money
UNITS = 1.351920 + 0.581854               # RSUs + DSUs, M

def npv_today(cu, au):
    """Casino 2022 FS after-tax NPV8, C$M, re-based by rules A2 and X1 (last stated slopes, added)."""
    k = FX / 1.25                           # study at C$1.25 per US$
    cu_s, au_s = cu * k, au * k
    cu_part = 3917 + (cu_s - 5.00) * 1132 if cu_s >= 4.50 else 3351 + (cu_s - 4.50) * 1132
    au_part = 3310 + (au_s - 2200) * (293 / 150)
    return cu_part + au_part - 2334

def _median(x):
    s = sorted(x); n = len(s)
    return s[n // 2] if n % 2 else (s[n // 2 - 1] + s[n // 2]) / 2

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {}))
    npv = npv_today(i['cu'], i['au'])
    m = i.get('m', _median(i['pnav']))
    eq_w = m * npv
    vps0 = eq_w / SHARES
    itm = [(n, k) for n, k in OPTIONS if k < vps0]          # options struck below the works value
    opt_money = sum(n * k for n, k in itm)
    sh_w = SHARES + sum(n for n, _ in itm) + (OPT_UNKNOWN if itm else 0) + UNITS
    Mw_ps = (eq_w + opt_money) / sh_w
    A = i['fail_c_lb'] / 100 * i['lb'] * FX + i['cash_fail']
    sh_f = SHARES + UNITS                                   # no option in the money at the fail value
    itm_f = [(n, k) for n, k in OPTIONS if k < A / sh_f]
    sh_f += sum(n for n, _ in itm_f); A += sum(n * k for n, k in itm_f)
    Mf_ps = A / sh_f
    P = i['P']
    E = (i['pw'] * Mw_ps + (1 - i['pw']) * Mf_ps) / P
    return dict(npv=npv, m=m, shares_works=sh_w, shares_fail=sh_f, Mw_ps=Mw_ps, Mf_ps=Mf_ps, M_stalled_ps=Mf_ps,
                Mw=Mw_ps / P, Mf=Mf_ps / P, E=E, per_year=E ** (1 / i['years']) - 1)

def levels(inp=None):
    """No raise, no warrants: the value per share does not depend on the price, so the levels are V / line."""
    i = dict(DEFAULTS, **(inp or {}))
    r = value(i); y = i['years']
    V = r['E'] * i['P']
    cheap = V / 2.0 ** (y / 4); exp = V / 1.1 ** (y / 4)
    return dict(cheap_below=cheap if cheap > r['M_stalled_ps'] else None, expensive_above=exp,
                fail_ps=r['M_stalled_ps'], V=V)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print({k: (round(v, 4) if v else v) for k, v in l.items()})
    assert round(r['E'], 2) == 1.62 and round(r['Mw'], 2) == 5.27 and round(r['Mf'], 2) == 0.40   # test line

# desk, 16 Nov: the counted case
DEFAULTS.update({'pw': 0.2})
