Why is there no cheap price?

A share counts as cheap here if, on average, it should be worth at least 2.00 times its price by Nov 2030. Worked out on paper, that would happen at C$1.35 a share. But at that price a share would still be worth C$2.32 if the project stalls, because that value is fixed at today's prices (what the market pays today for this company or for similar stalled projects) and does not fall with the share price. The sum would then say you make money even if everything goes wrong, which is not believable: if the share really fell that far, the value if it stalls would fall with it. So the page shows no cheap price instead of a misleading number.

Why

Expensive. At C$2.74 (close of Fri 13 Nov 2026) the expected value of a share in four years is 1.02 times today's price, 6.9% under the 1.1× line for expensive. The expected value weighs a share's value if the plan works and if it fails by their chances. Both outcomes are valued per pound of copper in the ground, as the market prices comparable projects today. If a pre-feasibility study (the second of the three standard mine studies) holds the first study's value and a mining company takes a stake in Altar by the end of 2029, a share is worth 1.45 times today's price (2.29 US cents a pound, the median of copper projects at that stage); if not, 0.84× (1.26 cents, the median of projects stuck at the first study, after four years of spending). The analyst's chance of success (a judgement): 30%. Valued on the projects' study values instead, both outcomes are far lower.

What would change the rating

Price alone won't make this cheap. What could raise the value: the first cash figure after the drilling season (statements due about 30 Nov 2026), the updated Altar resource (Q4 2026, its third date), an application for Argentina's RIGI investment regime (Q1 2027), the pre-feasibility study (2027), and a partner taking a project stake (no company date; the rankings' cut-off is 2029). On the numbers it turns fair if a partner pays about 2.7 US cents a pound or more (about US$172M for 20% of Altar), if copper projects at that stage re-rate above that level, or with copper above about US$6.67/lb.

Already expensive, by 6.9%. It would turn fair only below about C$2.54 with nothing else changed. It gets worse with a fourth date for the resource update, cash at 30 Sep 2026 far below C$27M, or a 2027 study with a capital cost well above US$2.0B.

Thesis breakers

Set in advance: any one of these would mean the plan has failed or the rating must be redone.

  • A partner pays at least US$172M for 20% or less of Altar (about 2.70 US cents a pound of the whole project's copper, about 31,800 million pounds, of which Aldebaran owns 80%), or a bid of at least C$4.16 a share, by 31 Dec 2029.
  • The PFS, by 31 Dec 2027, shows an after-tax value of at least US$3.0B at US$4.75 copper or less with initial capital cost of US$2.0B or less.
  • The median P/NAV today of copper projects with a pre-feasibility study rises to 0.13 or more (0.031 on 13 Nov 2026), or the share closes at or below C$1.64.

The rating function itself (Python)The exact code behind the card, the sliders and this calculation
# Aldebaran Resources (TSXV: ALDE) - value rating v0.4.1 (16 Nov 2026). C$ unless marked.
# Rule set v0.4.1: the value if it works may never be below the value if it fails, so both branches use the
# per-unit yardstick (EV per lb Cu, all categories, attributable; table C-3(a) v2); F1 cap 1.31 c/lb; F2 raise; q = 0.
FX = 1.5758 / 1.1052                      # C$ per US$, ECB 13 Nov 2026
DEFAULTS = dict(
    P=2.74,            # share price, C$ (start close 13 Nov 2026)
    pw=0.38,           # chance it works (desk)
    works_c_lb=2.29,   # works value, US c/lb: copper PFS median (Surge 0.83, Hot Chili 2.29, Solaris 3.76)
    fail_c_lb=1.26,    # stalled value, US c/lb: copper PEA median without Aldebaran (0.81, 0.97, 1.55, 1.60)
    cap_c_lb=1.31,     # F1 cap: Aldebaran's own EV per lb at the start close (US$332.5M / 25,440 Mlb)
    lb=25440.0,        # Mlb Cu attributable (80% of Altar, M&I 22.0 + Inf 9.8 Blb)
    centauri=19.525,   # C$M, 21,455,943 Centauri shares x C$0.91 (estimate, thin market)
    cash=33.561,       # C$M at 30 Jun 2026 (audited)
    spend_works=87.5,  # C$M spending 1 Jul 2026 - 31 Dec 2029 (estimate)
    spend_fail=66.2,   # C$M spending that builds nothing to 13 Nov 2030 (estimate)
    cu=6.173,          # copper US$/lb; the works value moves in proportion to Altar's own study line
    years=4.0,
)
SHARES = 185.442834
OPTIONS = [(0.10, 0.78), (4.57, 0.79), (0.13, 0.79), (7.15, 1.74), (0.10, 3.32), (3.99, 3.25)]  # (M, strike C$)

def npv_altar(cu):
    """Altar PEA, 100%, after-tax NPV8 US$M on the line through US$2,009M @ 4.35 and US$3,340M @ 5.00."""
    return 3340 + (cu - 5.00) * (3340 - 2009) / 0.65

def _branches(i, P):
    itm = [(n, k) for n, k in OPTIONS if k < P]                # options in the money at the price
    n_opt = sum(n for n, _ in itm); money = sum(n * k for n, k in itm)
    scale = npv_altar(i['cu']) / npv_altar(6.173)
    A_w = i['works_c_lb'] / 100 * i['lb'] * scale * FX + i['centauri']
    gap = max(0.0, i['spend_works'] - i['cash'] - money)       # rule C4, raised at the price less 20%
    sh_w = SHARES + n_opt + gap / (0.8 * P)
    Mw_ps = A_w / sh_w
    c = min(i['fail_c_lb'], i['cap_c_lb'])
    A_f = c / 100 * i['lb'] * FX + i['centauri']
    s = max(0.0, i['spend_fail'] - i['cash'] - money)          # rule F2 distressed raise
    n = SHARES + n_opt
    if A_f - s <= 0:
        Mf_ps = 0.0
    else:
        p = 0.8 * (A_f - s) / n
        Mf_ps = A_f / (n + s / p)
    return dict(Mw_ps=Mw_ps, Mf_ps=Mf_ps, shares_works=sh_w, shares_fail=n + (s / p if A_f > s else 0), gap=gap)

def value(inp=None):
    i = dict(DEFAULTS, **(inp or {}))
    P = i['P']; b = _branches(i, P)
    E = (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P
    return dict(b, M_stalled_ps=b['Mf_ps'], Mw=b['Mw_ps'] / P, Mf=b['Mf_ps'] / P, E=E,
                per_year=E ** (1 / i['years']) - 1)

def _E(i, P):
    b = _branches(i, P)
    return (i['pw'] * b['Mw_ps'] + (1 - i['pw']) * b['Mf_ps']) / P, b

def _cross(i, line, hi, lo=0.01, steps=4000):
    """Highest price at or below `hi` where E(P) >= line (scan down, then bisect)."""
    import math
    prev = hi
    for k in range(steps + 1):
        P = hi * math.exp(math.log(lo / hi) * k / steps)
        if _E(i, P)[0] >= line:
            a, b = P, prev
            for _ in range(60):
                mid = (a + b) / 2
                a, b = (mid, b) if _E(i, mid)[0] >= line else (a, mid)
            return a
        prev = P
    return None

def levels(inp=None):
    i = dict(DEFAULTS, **(inp or {})); y = i['years']; hi = 10 * i['P']
    exp = _cross(i, 1.1 ** (y / 4), hi)
    cheap = _cross(i, 2.0 ** (y / 4), hi)
    fail_ps = _E(i, cheap)[1]['Mf_ps'] if cheap else None
    return dict(expensive_above=exp, cheap_below=(cheap if cheap and cheap > fail_ps else None),
                cheap_arith=cheap, fail_ps_at_cheap=fail_ps)

if __name__ == '__main__':
    r = value(); l = levels()
    print({k: round(v, 4) for k, v in r.items()}); print(l)
    assert round(r['E'], 2) == 1.07 and round(r['Mw'], 2) == 1.45 and round(r['Mf'], 2) == 0.84   # test line

# desk, 16 Nov: the counted case
DEFAULTS.update({'pw': 0.3})
